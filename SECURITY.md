# Security

## Supported versions

Only the latest release of `termshot` gets security fixes.

## Reporting a vulnerability

Please report privately. Do not open a public issue.

- Go to the `Security` tab of `fayez-nazzal/termshot`.
- Choose `Report a vulnerability` to open a private advisory.
- Include the version from `termshot --version`, your OS, and the steps to reproduce.

You can expect a first reply within seven days.
